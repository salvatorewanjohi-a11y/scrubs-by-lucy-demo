# Scrubs by Lucy – store demo

A demo of the Scrubs by Lucy WooCommerce store that runs entirely in the browser with WordPress Playground.
The store is pre-built into site.zip, so each visit only has to unpack it.

- Store: https://playground.wordpress.net/?mode=seamless&blueprint-url=https://raw.githubusercontent.com/salvatorewanjohi-a11y/scrubs-by-lucy-demo/main/blueprint.json
- Store admin (products, stock, orders): https://playground.wordpress.net/?mode=seamless&blueprint-url=https://raw.githubusercontent.com/salvatorewanjohi-a11y/scrubs-by-lucy-demo/main/blueprint-admin.json

Each visit gets a fresh copy, so test orders are not kept.
